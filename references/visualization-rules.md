# 可视化规则

## 图表选择指南

| 分析目的 | 推荐图表 | 不推荐 |
|---------|---------|--------|
| 趋势变化 | 折线图 | 饼图 |
| 类别对比 | 柱状图 | 折线图 |
| 占比分布 | 饼图/环形图 | 散点图 |
| 相关关系 | 散点图 | 饼图 |
| 分布情况 | 直方图/箱线图 | 柱状图 |

## 设计原则

1. **数据墨水比**：最大化数据信息，最小化装饰元素
2. **颜色克制**：主色不超过 7 种，重点用强调色
3. **标签清晰**：轴标签、单位、数据来源必须标注
4. **对比明确**：使用基线、目标线辅助判断

## 常见错误

- 3D 图表（扭曲数据比例）
- Y 轴不从 0 开始（夸大变化）
- 双 Y 轴（容易误导）
- 过多数据点（信噪比低）
