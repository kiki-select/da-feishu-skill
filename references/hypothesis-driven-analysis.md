# 假设驱动分析法

## 核心理念

不是"看看数据说什么"，而是"用数据验证假设、驱动决策"。

## 分析流程

### 1. 明确核心问题
- 将模糊问题转化为具体、可验证的问题
- 好问题：「Q3 销售下降的主因是客单价降低还是客户流失？」
- 坏问题：「Q3 销售怎么样？」

### 2. 构建假设树
- 将核心问题分解为多个可验证假设
- 按 MECE 原则组织：相互独立、完全穷尽
- 示例：
  - H1: 客单价下降导致收入减少
  - H2: 高价值客户流失导致结构变化
  - H3: 新客获取放缓影响整体规模

### 3. 数据验证
- 为每个假设找到数据支撑或反驳
- 标注置信度：高/中/低
- 记录数据缺口

### 4. So What 追问链（至少 3 层）
```
数据现象 → 业务含义 → 行动建议 → 预期影响
```

**示例**：
- L1（现象）：Q3 华东区销售额下降 30%
- L2（含义）：核心市场份额被竞品侵蚀
- L3（行动）：调整华东区促销策略，增加大客户拜访
- L4（预期）：预计 Q4 恢复 15% 增长

## 输出标准

每个结论必须包含：
1. **数据支撑**：具体数字和来源
2. **行动指向**：明确的下一步建议
3. **可量化预期**：预估影响和时间线
